# Вектор — Equa.ai × Ventorme

Временный лендинг команды Equa.ai для Hacknext 2026. Помогает школьникам познакомиться с Ventorme и перейти к регистрации.

## Запуск

Требуется Python 3. В корне репозитория:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:4173. Остановить: Ctrl+C.

## Публикация

Это статический сайт без сборки и зависимостей. На хостинг загружать **только папку `dist`**. Локальный адрес не доступен участникам из интернета. Для сдачи нужен публичный URL.

Все кнопки регистрации ведут на одну командную ссылку:
https://ventorme.ai/register?utm_source=hacknext&utm_campaign=team-158

Менять номер команды не нужно. Собственной регистрации и хранения персональных данных нет. Опрос Google Forms открывается отдельно.

## Статус

Черновая версия в стилистике Ventorme: маскот Venti, мини-квиз, плавные переходы и адаптивная вёрстка. Возможности тарифа Free сверены с официальной главной. Интервью, результаты и гарантии поступления не выдуманы. До сдачи доработать сайт по пяти живым интервью и проверить путь до завершения онбординга.

Ответы мини-квиза не сохраняются и не отправляются. Источники материалов — ASSETS.md.

Проверка логики квиза (Node.js 18+): `node --test tests/quiz.test.mjs`.
