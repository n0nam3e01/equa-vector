# Источники оформления

Стиль ориентирован на официальный сайт https://ventorme.ai/, просмотренный 12 октября 2026: синий фон, лаймовые акценты, Manrope.

`dist/assets/venti.webp` — маскот Ventorme из публичного файла https://ventorme.ai/figma/studentlanding/v4f/hero-venti-quiz.webp. Использован по запросу пользователя для лендинга о Ventorme. Авторские права на Venti принадлежат правообладателю, а не Equa.ai.

`dist/assets/logo-ventorme.svg` — официальный логотип из https://ventorme.ai/figma/studentlanding/logo-ventorme.svg.

`dist/assets/venti-motion.webm` — официальная анимация с регистрации https://ventorme.ai/MotionCat_Ventorme_24-08_2.webm. `venti-poster.webp` и `venti.gif` получены преобразованием этого видео. На сайте используется лёгкий WebM с учётом уменьшенного движения; на телефоне маскот скрыт, видео не загружается. Кнопка паузы убрана по запросу пользователя. GIF доступен отдельным файлом.

Manrope подключается через Google Fonts с системным шрифтом на случай недоступности.

Вопросы мини-квиза, тексты и код написаны для проекта; код и тексты конкурента не копировались. Результат квиза — ориентир, не диагностика и не официальный профтест Ventorme.

Тариф Free сверён с официальной главной: мини-профтест, проверки уровня IELTS и SAT, настройка портфолио. Расширенные функции относятся к Plus. Цены не фиксируем.
